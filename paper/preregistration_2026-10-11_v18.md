# Pre-registration v18: transformer ensemble (iTransformer + TFT + PatchTST)

**Written:** 11 October 2026, ~02:00, **before any PatchTST (P17) prediction exists** (checked: no
`v17_predictions_P.parquet` on the Mac or julia2; 6 P17 fine-tuning tasks and its prediction job still
running). Scoring and the model-change rule as v6 §4-§6. Main model: YieldFormer-DE = v15 E15
(iTransformer Q12 + district error memory).

**Disclosure:** the idea was proposed by the user after the v17 TFT result was known (TE17 88.76% vs
E15 88.48% on 2010-2015, P 0.664; 88.91 vs 88.38 on 2016-2025). The iTransformer and TFT hindcast
numbers are therefore known; the PatchTST numbers are not. To keep this from being tuned on test
years, the recipe below has no free choices.

## 1. Arm X18: equal-weight transformer ensemble

For every district-crop-year: the mean of the three per-crop fine-tuned 3-seed ensemble forecasts
Q12 (iTransformer), T17 (TFT) and P17 (PatchTST), each from its own rolling fold (train ≤ Y−2,
validate Y−1, test Y; same rows, same y_hist). Weights fixed at 1/3 each. No model is dropped, no
weight is fitted, whatever P17's own result is.

**XE18** = X18 corrected by the v15 §2 district error memory using X18's own past errors (λ chosen
causally on 2011..Y−1, grid 0..1 step 0.05).

## 2. Decision (v6 §6, hindcast 2010-2015)

XE18 replaces E15 as the main model if macro MSE skill vs y_hist is higher with year-block bootstrap
P(Δ > 0) ≥ 0.95, pooled MAPE is lower, and no crop is worse in every year. Independently of v17:
if XE18 and a single-model arm (TE17/PE17) both pass against E15, the one with the higher macro skill
on 2010-2015 is chosen. The name YieldFormer-DE stays for the method. Reported, not decisive:
2016-2025, 2010-2025, per crop, XE18 vs TE17 and vs PE17, and the one non-transformer reference GE16.

No other ensemble (two-model subsets, weighted, stacked) is evaluated; the number of hindcast
decisions grows to 12 (v7-v15: 9; v17: TE17, PE17; v18: XE18), Bonferroni level P ≥ 0.9958, reported.

## 3. Forecasts

A main-model change only takes effect for future forecasts, each frozen separately; the frozen
YieldFormer-DE (Q12) 2026 and 2027 files are never changed. An ensemble 2026 forecast needs fold-2026
TFT and PatchTST networks (same protocol as v16 §4.1, data end 2026-09-19).
